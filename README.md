# Алхам — арилжааны тэмдэглэл

Deriv-ийн **Step Index (100–500)** болон **XAUUSD** арилжаанд зориулсан арилжааны тэмдэглэлийн вэб программ. *The Disciplined Trader*, *Trading in the Zone*, *Best Loser Wins* номын сахилга бат, магадлалын сэтгэлгээ, алдагдлыг удирдах зарчмууд дээр суурилсан.

## Боломжууд

- **Самбар**: цэвэр P/L, хожлын хувь, дундаж R, profit factor, сахилга батын хувь, дансны өсөлтийн муруй, P/L-ийн календарь, хэрэгсэл / мэдрэмж / setup / сешн / цагаар задаргаа
- **Арилжаа бүртгэх**: эрсдэлийн %-аар лотын зөвлөмж, R:R, Step Index-ийн алхмын тоо, дүрэм зөрчлийн анхааруулга
- **Өдрийн бэлтгэл**: 8 асуулттай шалгах хуудас (АРИЛЖ / ЗОГС), өдрийн алдагдал ба арилжааны тооны хязгаар
- **20 арилжааны дасгал**: дүрмээ дараалан баримтлах механик шатны дасгал
- **Дүгнэлт**: долоо хоногийн дүгнэлт, сарын итгэл үнэмшлийн дасгал
- **Тохиргоо**: данс, эрсдэл, хэрэгслийн гэрээний нөхцөл, JSON нөөц / CSV экспорт

## Ашиглах

GitHub Pages дээр нээгээд шууд ашиглана. Суулгах шаардлагагүй. Утсан дээр хөтчийн "Нүүр дэлгэцэнд нэмэх" сонголтоор апп мэт ашиглаж болно.

## Өгөгдөл хаана хадгалагдах вэ

Хоёр горимтой:

- **Сервергүй (анхдагч):** өгөгдөл тухайн хөтчид хадгалагдана. Хөтчөө цэвэрлэвэл устах тул **Тохиргоо → JSON нөөц татах** товчоор тогтмол нөөцлөөрэй.
- **Supabase сервертэй:** имэйл, нууц үгээр нэвтэрч, бүх төхөөрөмж дээр ижил өгөгдөлтэй ажиллана. Интернэт тасарсан үед өөрчлөлтүүд түр хадгалагдаж, холбогдоход автоматаар илгээгдэнэ.

## Supabase сервер тохируулах (нэг удаа)

1. [supabase.com/dashboard](https://supabase.com/dashboard) дээр **New project** үүсгэнэ. Бүс (Region): **Northeast Asia (Tokyo)** эсвэл **Southeast Asia (Singapore)**.
2. **SQL Editor → New query** хэсэгт [`supabase/schema.sql`](supabase/schema.sql)-ийн агуулгыг бүтнээр нь хуулж тавиад **Run** дарна.
3. **Authentication → URL Configuration** хэсгийн **Site URL**-д `https://mbabuu96-cyber.github.io/ginj/` гэж оруулаад хадгална.
4. **Project Settings → API Keys** (эсвэл дээд талын **Connect** товч) хэсгээс **Project URL** болон **anon / publishable** түлхүүрийг хуулна.
5. Программын **Тохиргоо → Сервер (Supabase)** хэсэгт хоёуланг нь оруулж **Холбох** дарна. Дараа нь **Бүртгүүлэх** → имэйлээ баталгаажуулах → **Нэвтрэх**.
6. Хөтчид өмнө нь оруулсан арилжаа байвал **"…арилжааг серверт нэмэх"** товчоор серверт хуулна.

`service_role` эсвэл `sb_secret_` гэж эхэлсэн нууц түлхүүрийг хэзээ ч программд бүү оруул. Мөр бүрийн хамгаалалт (RLS) асаалттай тул хэрэглэгч бүр зөвхөн өөрийн өгөгдлийг харна.

## Гэрээний нөхцөл

Step Index-ийн гэрээний хэмжээ 10, XAUUSD-ийнх 100 гэсэн анхны утгатай. MT5 дээр хэрэгсэл дээр баруун товшоод **Specification**-ийг нээж тулгаад, шаардлагатай бол **Тохиргоо → Хэрэгслүүд**-ээс засна уу.

P/L = (Гарах − Орох) × Лот × Гэрээний хэмжээ (Sell бол эсрэг тэмдэгтэй) + шимтгэл/своп. MT5-ын бодит P/L-ийг оруулбал тэр нь давуу эрхтэй.
